## 🌍 Overview

**AidBridge** is a unified digital platform designed to strengthen social care delivery by connecting vulnerable children and elderly individuals with the support systems they need.

It brings outreach workers, shelters, hospitals, case managers, NGOs and government administrators into a coordinated ecosystem where assistance can be requested, assigned, delivered, tracked and verified.

Traditional assistance systems often operate in disconnected environments. A referral may be created, but there is no guarantee that the individual actually received the required support.

AidBridge addresses this gap through transparent case management, coordinated service referrals and verified service delivery.

**Our principle is simple: Assistance is not complete until care is delivered and verified.**

## 🎯 The Problem We Address

Vulnerable individuals frequently face barriers to essential support:

- Limited access to safe shelter, food, healthcare and clothing.
- Fragmented communication between assistance providers.
- Untracked referrals and delayed interventions.
- Lack of visibility into unresolved cases.
- Difficulty verifying whether assistance was actually delivered.
- Inadequate coordination between organisations.

AidBridge transforms disconnected assistance processes into a structured, accountable and traceable social care workflow.

## 🔄 How AidBridge Works

1. **Identify** — An outreach worker registers an individual who needs assistance.
2. **Assess** — Essential needs are documented and urgency is evaluated.
3. **Connect** — The case is referred to an appropriate service provider.
4. **Coordinate** — The receiving organisation reviews and accepts the referral.
5. **Deliver** — The actual service or assistance is provided.
6. **Verify** — An authorised user records and verifies service delivery.
7. **Resolve** — The case can be closed only after the required verification conditions are satisfied.

This workflow creates accountability throughout the assistance lifecycle.

## 👥 Stakeholder Ecosystem

AidBridge supports five primary operational roles:

- **Government Administrator:** System-wide oversight, organisation management, analytics and audit monitoring.
- **Outreach Worker:** Field registration, needs assessment and urgent intervention.
- **Shelter Coordinator:** Shelter capacity, admissions, discharges and resource management.
- **Hospital Coordinator:** Medical referrals and assistance delivery records.
- **Case Manager:** Case coordination, follow-ups, escalation and service verification.

Each stakeholder receives role-appropriate access and workflows.

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS)
- npm
- PostgreSQL (if using the configured database architecture)
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/AidBridge.git
```

Navigate into the project:

```bash
cd AidBridge
```

Install dependencies:

```bash
npm install
```

Configure environment variables using the provided `.env.example` file.

Run database migrations if Prisma and PostgreSQL are configured:

```bash
npx prisma migrate dev
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

*Use only the setup commands supported by the current project configuration.*
